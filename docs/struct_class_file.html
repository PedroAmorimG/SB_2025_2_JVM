std::string ClassFile::resolve_utf8 ( u2 index) const
inline

Resolve um índice da Constant Pool para sua representação em String.

  • Esta função é recursiva. Se o índice apontar para uma ClassInfo, ela busca o nome da classe. Se apontar para NameAndType, busca o nome e descritor.
  • Parameters
    indexO índice na constant pool a ser resolvido.
    Returns
    A string resolvida (ex: "java/lang/Object") ou vazia em caso de erro.
