\doxysubsection{Detailed Description}
Representa um array alocado na Heap da JVM. 

Esta classe lida com dois tipos de armazenamento\+:
\begin{DoxyEnumerate}
\item Primitivos (int, float, byte, etc.)\+: Armazenados como bytes brutos no vetor {\ttfamily \doxylink{class_runtime_array_a9a8cbcca314d855072717dbff34cf369}{raw}}.
\item Referências (Object\mbox{[}\mbox{]}, String\mbox{[}\mbox{]}, etc.)\+: Armazenados como ponteiros no vetor {\ttfamily \doxylink{class_runtime_array_aebd3b5c10ec2e684cab7e37234614080}{refs}}. 
\end{DoxyEnumerate}
