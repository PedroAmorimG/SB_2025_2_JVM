\doxysubsection{Detailed Description}
Responsável pela leitura e análise (parsing) do arquivo binário .class. 

Esta classe encapsula a lógica de abrir o arquivo, ler bytes sequencialmente (respeitando o Big-\/\+Endian) e preencher a estrutura \doxylink{struct_class_file}{Class\+File}.
