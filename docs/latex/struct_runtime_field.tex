\doxysubsection{Detailed Description}
Representação de um campo (field) de uma classe em tempo de execução. 

Diferente do \doxylink{struct_field_info}{Field\+Info} (que é estático), o \doxylink{struct_runtime_field}{Runtime\+Field} sabe o seu offset (posição) dentro dos dados do objeto, permitindo acesso rápido na memória.
